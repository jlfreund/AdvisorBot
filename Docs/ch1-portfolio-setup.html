Chapter 1 Setup Guide

Setting Up Your Portfolio

Workspace initialization, statement ingestion, portfolio configuration, and custom parser plugin development.

Everything runs locally on your machine with private files stored inside the gitignored Portfolios/ directory. Follow the 5 quick steps below—each step pairs a short instruction with a ready-to-copy AI prompt, while manual commands and developer details stay tucked inside expandable drawers.

Platform Commands:
Before You Start — Install & Launch: Make sure Python 3.11+, Git, and your AI coding CLI (Claude Code, Gemini CLI, Codex CLI, Cursor, or Antigravity) are installed, then paste this prompt in the cloned folder to set up .venv and open the dashboard:
Setup Prompt Create .venv, Install Dependencies & Launch Dashboard 
Read pyproject.toml and set up this AdvisorBot checkout for my OS:
1. Verify Python 3.11+ is available and create a `.venv` virtual environment at the repo root if missing.
2. Install dependencies with `.venv` (`pip install -e ".[mcp,ingest,ui]"`).
3. Start the local server with `--port 8765 --open` (`Scripts/advisorbot_server.py`) so the dashboard opens in my browser.
Manual Commands & Package Details (macOS / Linux / Windows) CLI / AI Reference

Core portfolio math uses Python stdlib; optional extras in pyproject.toml enable PDF/XLSX ingestion (ingest: pypdf, openpyxl), badge image uploads (ui: Pillow), external agents (mcp), and tests (dev: pytest). Public quotes require Yahoo Finance access during refresh.

macOSTerminal (zsh / bash)
git clone <repository-url> && cd AdvisorBot
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -e ".[mcp,ingest,ui]"   # Add ,dev if running pytest
.venv/bin/python Scripts/advisorbot_server.py --port 8765 --open
LinuxTerminal (bash / zsh)
git clone <repository-url> && cd AdvisorBot
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -e ".[mcp,ingest,ui]"   # Add ,dev if running pytest
.venv/bin/python Scripts/advisorbot_server.py --port 8765 --open
Headless/WSL without a desktop browser opener: omit --open and open the printed http://127.0.0.1:8765/?token=... link.
WindowsPowerShell / Command Prompt
git clone <repository-url>; cd AdvisorBot
py -3 -m venv .venv; .\.venv\Scripts\Activate.ps1
python -m pip install -e ".[mcp,ingest,ui]"   # Add ,dev if running pytest
.\.venv\Scripts\python.exe Scripts\advisorbot_server.py --port 8765 --open
If PowerShell script activation is blocked, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once, or run .\.venv\Scripts\python.exe directly.

1 Create & Complete Your Portfolio in Settings

In the browser, open Settings (⚙️) → Portfolio, click + New Portfolio, and fill in your Portfolio Name, Annual Burn Rate, Tax State & Rates, and at least one member in Family Members (Name + Birthdate) so Select Portfolio becomes active.

Optional Prompt Initialize & Configure Portfolio From the CLI Instead 
Read Examples/project.example.json and Scripts/config.py (specifically validate_portfolio_config). Help me initialize `Portfolios/<portfolio_slug>/` with `Statements/`, `Scenarios/`, `Plugins/`, `Assets/`, and a valid `project.json`, ask me only for the required household/tax/member fields, verify `validate_portfolio_config` passes cleanly, and set `Portfolios/_active.json`.
5-Tab Settings Guide, Incomplete Validation Rules & Manual CLI Init UI & AI Reference

What Each Tab in Portfolio Settings (⚙️) Configures

Manual CLI Initialization & Validation Rules (validate_portfolio_config)

A portfolio remains marked Incomplete (disabling Select Portfolio) until household_name, reference_annual_burn > 0, tax_rates.state_code (or FED), tax_rates.ltcg_top, tax_rates.ordinary_top, and at least one entry in investors with name + birth_date are present.

3 Add Your Statements

Copy brokerage or stock-plan statements into Portfolios/<slug>/Statements/, and upload official ssa.gov .xml earnings files per investor inside Settings (⚙️) → Family Members.

Supported Built-In Formats & Statement Directory Rules Reference
  • Morgan Stanley & StockPlan Connect (Statements/*.pdf, Statements/*.xlsx): Monthly/quarterly brokerage PDFs (including UMA sleeves & Muni SMAs), unvested grant PDFs, and StockPlan Connect Activity .xlsx reports.
  • Wells Fargo Advisors (Statements/*.pdf): Consolidated SNAPSHOT brokerage, IRA/Roth IRA, and annuity summary rows.
  • Social Security Administration (ssa.gov .xml): Upload in Settings → Family Members → Select ssa.gov XML file (stored under Statements/SSN/). Raw .xml files placed directly in Statements/ are skipped by CLI refresh (scanner.py scans .pdf, .xlsx, *.statement.json, and *.grants.json).
  • Canonical JSON Schemas (*.statement.json, *.grants.json): Zero-code structured imports from any institution (see Step 5).

4 Rescan & Refresh

In Settings (⚙️) → Portfolio, click ↻ Rescan and then click ⚙ Portfolio Refresh to ingest green Available files—if any files stay red Unknown, proceed to Step 5.

Status Pill Meanings & Local Session Auth Details Reference
Pill StatusMeaningAction
ProcessedAlready ingested and reconciled in portfolio.sqlite.None needed.
AvailableMatched a parser dry-run and ready to ingest.Click ⚙ Portfolio Refresh (unghosts automatically).
UnknownNo enabled parser matched this layout yet.Run Step 5 below.

Why --open & Session Auth exist: Because 127.0.0.1 is shared locally, --open performs a one-time /?token=... handshake backed by Data/.session_secret (0600), storing a 1-year HttpOnly; SameSite=Strict cookie so server restarts reconnect automatically. Re-run --open if switching between 127.0.0.1 and localhost or using a fresh browser profile.

5 Onboard Unsupported Statements With AI

For any statement marked Unknown (e.g. Fidelity, Schwab, Vanguard, TIAA, E*TRADE), open your AI CLI inside AdvisorBot, copy this prompt, and then click ↻ Rescan → ⚙ Portfolio Refresh once it finishes:

Primary Prompt Inspect, Build & Test a Custom Parser Plugin 
Onboard the unparsed statement at `Portfolios/<portfolio_slug>/Statements/<statement_file>`.

Read these references first:
- .agents/skills/statement-onboarding/SKILL.md
- Scripts/ingest/framework.py, Scripts/ingest/models.py, and Scripts/ingest/classification.py
- Scripts/ingest/plugins/wells_fargo.py (and morgan_stanley_activity.py for XLSX)

Then:
1. Run `Scripts/holdings.py inspect-statement "Portfolios/<portfolio_slug>/Statements/<statement_file>" --max-pages 12` (keep default redaction enabled).
2. Write a `StatementPlugin` in `Portfolios/<portfolio_slug>/Plugins/<institution>_plugin.py` scoring > 0.80 in `detect()`, resolving accounts via `ctx.resolve_account_metadata(...)`, setting valid `(asset_class, risk_class)` pairs across the 7-class taxonomy (`classify_public_security()` for public tickers), and setting `reported_total`.
3. Add `"<institution>_plugin.py"` under `"allowed_plugins"` in `Portfolios/<portfolio_slug>/project.json`.
4. Verify with `Scripts/holdings.py test-plugin "Portfolios/<portfolio_slug>/Statements/<statement_file>" --offline` until exit code 0 (passing detect, RiskClass gate, and ±$0.05 checksum), and run `pytest Scripts/tests/scans/ -q`.
Alternative Prompts: One-Off JSON Import or Upstream Community PR Optional Prompts

Use Prompt 2 when you just want a one-time conversion from CSV/PDF into AdvisorBot's zero-code JSON schema, or Prompt 3 to contribute a sanitized parser back into the main repository with tests:

Prompt 2 Zero-Code Canonical JSON Import (*.statement.json / *.grants.json) 
Convert `Portfolios/<portfolio_slug>/Statements/<source_file>` into canonical `Portfolios/<portfolio_slug>/Statements/<output_name>.statement.json` (or `.grants.json` for equity grants). Read `Scripts/ingest/plugins/canonical_json.py`, `grant_json.py`, `Examples/grants.example.json`, and `Scripts/ingest/classification.py` first, then verify with `Scripts/holdings.py test-plugin "Portfolios/<portfolio_slug>/Statements/<output_name>.statement.json" --offline`.
Prompt 3 Promote a Parser Upstream & Add Golden Regression Tests 
Promote `Portfolios/<portfolio_slug>/Plugins/<institution>_plugin.py` into a PII-free built-in parser. Read `Scripts/ingest/plugins/__init__.py`, `Scripts/ingest/plugins/wells_fargo.py`, `Scripts/ingest/wells_fargo.py`, and `Scripts/tests/parsers/test_golden_pages.py` first. Move sanitized parsing code to `Scripts/ingest/` & `Scripts/ingest/plugins/`, register it in `build_default_registry()`, add synthetic golden fixtures (`*.pages.txt` with `\f\n` separators + `*.expected.json`) under `Scripts/tests/fixtures/parsers/<institution>/`, and verify `pytest Scripts/tests/parsers/ Scripts/tests/scans/ -q` passes cleanly.
AI & Developer Reference: Doc Pointers, inspect-statement / test-plugin Flags & Privacy AI / Dev Reference

Privacy note: Sharing raw statements with cloud AI tools exposes account details—prefer Section 3.6 redaction practices, a local offline model, or inspect-statement (redacts 7+ digit runs by default; pass --unredacted only locally).

CLI Commands, Flags & Reload: Clicking ↻ Rescan in Settings → Portfolio reloads opted-in plugins from project.json without restarting the server. For CLI verification, use Scripts/holdings.py test-plugin <file> with --offline (no Yahoo calls), --plugins-dir <dir> (test before project.json opt-in), --no-strict-checksum (warn instead of fail on >$0.05 mismatch), and --json. Exit codes: 0 pass, 2 detect missed, 3 parse or RiskClass error, 4 strict checksum mismatch.
