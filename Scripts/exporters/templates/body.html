External Agent Bridge (MCP)
Allows desktop AI agents (Claude Desktop, Cursor) to run queries and simulations over local desktop IPC. In-app features (browser AI Chat, simulator) do not use MCP and work completely when disabled.
⚠️ Security Advisory: Indirect Prompt Injection Risks
The MCP service has no network egress, communicates strictly over local desktop IPC, and routes all portfolio responses through your active Privacy Shield profile. However, if an external CLI agent has access to both AdvisorBot's MCP service and general-purpose network tools (like curl, shell commands, or web browsing), malicious text inside an untrusted document or webpage could trick the agent into exfiltrating portfolio data or modifying scenarios.
Best Practice: Keep MCP Disabled unless actively needed. When enabled, connect it only to sandboxed desktop environments without ambient web-browsing capabilities.
